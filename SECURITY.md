# Security policy

AdBrake makes no network requests of its own except the weekly download of three public
filter lists and, on Twitch only, requests to Twitch's servers (see the privacy policy in
`docs/store/privacy-policy.md`). It collects no data.

## Reporting a vulnerability
Please report privately, not in a public issue: use GitHub's "Report a vulnerability" button
on the repository's Security tab (private advisory). Include the version, steps to reproduce
and the impact. You will get a reply within a few days; this is a one-person hobby project, so
there is no bounty.

## Supported versions
Only the latest release.
