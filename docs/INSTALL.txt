AD SHIELD - HOW TO INSTALL
==========================

Ad Shield is free. It is not in the Chrome Web Store: you install it from this
folder. It works in Google Chrome, Microsoft Edge and Brave (version 120 or newer).


1. FIRST: PUT THE FOLDER WHERE IT CAN STAY
------------------------------------------
Unzip the zip file. You get a folder called "ad-shield" (it contains
manifest.json and this INSTALL.txt). Windows "Extract All" may put it inside
another folder named like the zip: use the inner "ad-shield" folder.

Move that folder to a permanent place, for example:
  Windows: C:\Users\<you>\Documents\ad-shield
  macOS:   your Documents folder

Do not leave it in Downloads, and do not delete, rename or move it later:
the browser runs the extension from this folder. If the folder is gone, the
extension stops working.


2. INSTALL ON WINDOWS
---------------------
Google Chrome:
  1. Type chrome://extensions in the address bar and press Enter.
  2. Turn on "Developer mode" (switch at the top right).
  3. Click "Load unpacked".
  4. Choose the "ad-shield" folder (the one that contains manifest.json).
  5. Reload tabs that were already open.

Microsoft Edge:
  1. Type edge://extensions in the address bar and press Enter.
  2. Turn on "Developer mode" (switch in the left column, near the bottom;
     on a narrow window open the menu at the top left first).
  3. Click "Load unpacked" and choose the "ad-shield" folder.
  4. Reload tabs that were already open.

Brave:
  1. Type brave://extensions in the address bar and press Enter.
  2. Turn on "Developer mode" (switch at the top right).
  3. Click "Load unpacked" and choose the "ad-shield" folder.
  4. Reload tabs that were already open.


3. INSTALL ON macOS
-------------------
Double-click the zip to unzip it, move the "ad-shield" folder to Documents,
then in Google Chrome:
  1. Type chrome://extensions in the address bar and press Return.
  2. Turn on "Developer mode" (top right).
  3. Click "Load unpacked" and choose the "ad-shield" folder.
Edge (edge://extensions) and Brave (brave://extensions) work the same way.


4. THE "DEVELOPER MODE" MESSAGE IS EXPECTED
-------------------------------------------
Because the extension is not from the store, the browser may show a message
such as "Disable developer mode extensions" when it starts. That is normal.
Close it with the X. Do not click "Disable" or "Turn off", or Ad Shield is
switched off until you turn it on again in the extensions page.
Leave "Developer mode" on.


5. PIN THE ICON AND OPEN THE SETTINGS
-------------------------------------
Pin: click the puzzle-piece (Extensions) icon next to the address bar and
click the pin next to "Ad Shield" (Edge: the eye icon, "Show in toolbar").

The Ad Shield button shows what was blocked on the current page, has a switch
to turn blocking off for one site, and "Hide an element on this page" to
remove anything else you do not want to see.

Settings: click the Ad Shield button and then "Settings", or right-click the
icon and choose "Options".


6. FILTER LISTS UPDATE THEMSELVES
---------------------------------
Once a week Ad Shield downloads the newest EasyList, EasyPrivacy and EasyList
Cookie List by itself. You do not need to do anything. "Update now" is in
Settings, under "Filter lists".


7. UPDATING TO A NEW VERSION
----------------------------
  1. Unzip the new zip somewhere temporary.
  2. Open your existing "ad-shield" folder, delete everything inside it, and
     copy everything from the new "ad-shield" folder into it.
     Keep the same folder in the same place: then your settings, your
     allowed sites and "My filters" are kept.
  3. Open chrome://extensions (edge://extensions, brave://extensions) and
     click the reload icon (circular arrow) on the Ad Shield card.
  4. Reload open tabs.


8. UNINSTALL
------------
Open chrome://extensions (edge://extensions, brave://extensions), click
"Remove" on the Ad Shield card, then delete the "ad-shield" folder.


PRIVACY
-------
No accounts, no telemetry, no remote configuration. The only requests the
extension itself makes are the weekly downloads of the three public filter
lists (and, on Twitch only, requests to Twitch's own servers for an ad-free
copy of the stream you are watching). Settings stay in your browser.
