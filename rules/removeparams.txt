# Ad Shield tracking-parameter list (our own list, MIT licence, like the rest of the code).
# Names in the sections marked [Brave] and [DDG] were taken from Brave's query-filter.json
# (brave/adblock-lists, MPL-2.0) and DuckDuckGo's tracking-parameters.json
# (duckduckgo/privacy-configuration, Apache-2.0), checked 2026-11-25; see rules/NOTICE.md.
# Turned into rules/removeparam.json by tools/removeparam.py (run python3 -I tools/build_rules.py
# --curated-only to rebuild it offline).
#
# One query-parameter name per line, spelled out exactly: Chrome's queryTransform.removeParams
# matches whole names only (no wildcards, no prefixes) and is case-sensitive. "#" starts a
# comment. Every name here must be tracking-only: removing it must never change what the page
# shows. Generic names (ref, source, id, cid, campaign, si, ...) are refused by the build because
# sites use them for real content (tools/removeparam.py NEVER).
# Removed only from top-level pages and frames (main_frame, sub_frame), only when one of these
# names is in the query string.

#             Instagram); this list has no per-site scoping, so they stay.
