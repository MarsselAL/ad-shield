# Filter list data in `rules/`

The files generated by `tools/build_rules.py` are adaptations of third-party filter lists:

| Files | Source | Licence used |
|---|---|---|
| `ads_N.json` (numbered), `cosmetic/ads_generic.css`, `cosmetic/ads_generic_top.css`, `cosmetic/ads_excepted.css`, the `ads` parts of `cosmetic/site/*.json`, `cosmetic/generic.json` and `cosmetic/generic_excepted.json` | [EasyList](https://easylist.to/easylist/easylist.txt) | CC BY-SA 3.0 |
| `privacy_N.json` (numbered), `cookie_strip.json` | [EasyPrivacy](https://easylist.to/easylist/easyprivacy.txt) | CC BY-SA 3.0 |
| `cookies_N.json` (numbered), `cosmetic/cookies_generic.css`, `cosmetic/cookies_excepted.css`, the `cookies` parts of `cosmetic/site/*.json`, `cosmetic/generic.json` and `cosmetic/generic_excepted.json` | [EasyList Cookie List](https://secure.fanboy.co.nz/fanboy-cookiemonster.txt) | CC BY 3.0 (list header); distributed here under CC BY-SA 3.0 |

Changes made: the lists were converted mechanically to Chrome declarativeNetRequest rules and
CSS/JSON cosmetic data; filters that cannot be expressed that way were left out (counts per
reason in `build-info.json`, which also records the list versions used). The derived files in
this folder are shared under CC BY-SA 3.0. This ShareAlike licence applies to these data files
only; the extension's code is MIT (see `../LICENSE`).

`client_ads.json` and `trackers.json` are this project's own Twitch rules (MIT).

`curated_hosts.txt` is this project's own hand-written host list, and `ads_curated.json` and
`privacy_curated.json` are generated from it only (by `tools/curated.py`); all three are this
project's own data under the MIT licence (see `../LICENSE`), not derived from the lists above.

`removeparams.txt` (and `removeparam.json`, generated from it by `tools/removeparam.py`) is this
project's own list under the MIT licence. Some of its parameter names were taken from two
published lists, checked on 2026-11-25; the sections that use them are marked `[Brave]` and
`[DDG]` in the file:

| Source | Licence |
|---|---|

| DuckDuckGo `features/tracking-parameters.json` (https://github.com/duckduckgo/privacy-configuration) | Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0) |
